# 💣 A robots.txt group inherits NOTHING from "User-agent: *". A crawler obeys the
# group that names it and ignores every other one. The AI/social crawlers below used
# to stand alone with "Allow: /" and no Disallow at all -- so the eleven agents that
# pull the most were the only ones with access to /admin/, and to /api/ and the 65,521
# map tiles as well. That is why the rules are repeated verbatim in BOTH groups:
# adding a line to one group only is the exact failure mode this file was in.
#
# 💣 Never write a blanket "Disallow: /*?". Every JS and CSS file is served through
# ?v=<contenthash> (AGENTS.md sec.7) -- a blanket query ban would take all scripts and
# stylesheets away from Google. And ?lang=en is the hreflang alternate listed in
# sitemap.xml. Name the parameters, never the pattern.
#
# The planner state is deliberately absent here: since 2026-07-06 the app no longer
# writes it into the address bar (syncPlannerStateToUrl in
# js/map-features/map-features-layer-state.js), so there is no combinatorial URL space
# left to fence off.
#
# ⚠️ NOT listed, on purpose: the Wiki Aventurica deep links (?siedlung= ?staat=
# ?region= ?strasse= ?fluss=). They are linked from OUTSIDE. A disallowed but
# externally linked URL can still be indexed -- just without a snippet, because the
# crawler may no longer read it. The canonical in index.html already consolidates them
# onto "/", and blocking them would make that canonical unreadable. Leave them
# crawlable.
