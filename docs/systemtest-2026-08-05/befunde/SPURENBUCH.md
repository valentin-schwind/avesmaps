# Spurenbuch — jede Änderung an Produktivdaten

**Regel:** Wer auf avesmaps.de etwas anlegt, ändert oder löscht, trägt es **sofort nach
dem Schreiben** hier ein — nicht am Ende, nicht aus dem Gedächtnis. Eine Zeile pro Objekt.

Format (eine Tabellenzeile):

| Zeit | Agent | Was (Typ) | Bezeichner / ID | Wo (Editor/Endpunkt) | Aufgeräumt? |
|---|---|---|---|---|---|

- **Bezeichner** muss ausreichen, um das Objekt ohne diese Session wiederzufinden.
- Alle Testobjekte tragen im Namen das Präfix **`ZZ-Systemtest`**, damit sie auch dann
  auffindbar sind, wenn diese Datei verlorengeht.
- **Aufgeräumt?** bleibt `nein`, bis das Löschen/Zurücknehmen **verifiziert** ist
  (erneut nachgeschaut, nicht nur geklickt).
