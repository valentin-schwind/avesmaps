Was das Mockup behauptet und was noch offen ist. Alle Faktoren stehen in einer Einheit: dem Geländefaktor der Quelle, Straße = 1,0 — dieselbe Skala, die im Code schon existiert (AVESMAPS_SEASON_GROUND_PATH_FACTORS, season-ground.php:49). Die heutige Spalte offroad_factor hält den Kehrwert (1,40 für Wald) und wird abgelöst, nicht umgedeutet. Offen: ob die Wegtypen wirklich auf die GA-Werte zurückgesetzt werden sollen — das ändert jede Reisezeit auf jeder Straße, nicht nur querfeldein.
