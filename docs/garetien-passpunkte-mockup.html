Passpunkte — trägt eine Korrektur aus Fixpunkten?

Die Editoren melden Versätze an einzelnen Orten und wollen daraus eine Korrekturmatrix bauen. Die Frage davor lautet: trägt so eine Korrektur auch dorthin, wo kein Fixpunkt liegt? Diese Seite zeigt, wie die Antwort aussieht — und woran man sie erkennt.

Das Urteil

Nachbarnvorhernachher besserEinigkeit

vorher / nachher = Median des Fehlers in Meilen, bevor und nachdem jeder Ort aus seinen Nachbarn korrigiert wurde — er selbst zählt dabei nie mit. Einigkeit = zeigen die Nachbarn in dieselbe Richtung (1 = ja, 0 = gar nicht)?

Die Behauptung „je weiter Westen, desto weiter Süden“
